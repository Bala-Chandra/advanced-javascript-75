## VS Code debugger

Open `programs/08-array-transformations/run.js`, add a breakpoint in `solution.js`, and press F5 with **Debug current program file**. F10 = step over, F11 = step into, Shift+F11 = step out. Inspect Watch and Call Stack. Repeat in any folder.
