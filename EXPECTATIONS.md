# Advanced JavaScript — Expectations & Definitions

## Learning contract
Each numbered folder contains a reference implementation (only when source-backed), an untouched `practice.js`, a runner, tests, detailed per-problem README, and a variations folder. Before practice, predict the output and explain the original. Then write `practice.js` independently. Do not substitute guessed solutions for inaccessible originals.

## Universal mastery checklist

1. Definition and why it exists.
2. Inputs, outputs, examples, and edge cases.
3. Junior-level line-by-line dry run.
4. Staff-level discussion of trade-offs, semantics, performance and security.
5. Test failures and debugger investigation.
6. Independent practice.js implementation.
7. Follow-up variations as separate programs.
8. Vue, React, Node.js or NestJS application when relevant.
